# 一次接线图组态工具用户指南

本指南说明当前版本中可见的场站、一次图、图元、设备模板、设备绑定、预览和发布操作。内容以编辑器实际界面为准。

## 1. 认识工作区

打开工具后默认进入编辑页，主要区域如下：

- **顶部工具栏**：撤销/重做、画布复位、删除、组件树、对齐、组合、连线、保存、缩略图下载、预览、发布，以及侧栏、全屏、画布锁定和日夜模式控制。
- **左侧栏**：三个页签，分别为“场站”“图元”“模版”。
- **中央画布**：放置和编辑一次接线图内容。
- **右侧栏**：未单选图元时显示页面设置；单选一个图元时显示“配置”，适用时还会显示“绑定”。
- **底部状态栏**：显示最近更新时间、当前场站、当前图纸和连接状态。

顶部左右两端的折叠按钮可收起或展开左右侧栏。右上角依次提供全屏、全局锁定和日间/夜间模式切换。

连接状态以当前一次图绑定的 MCU 地址为准，显示“连接检测中… / 已连接 / 未连接”。设备列表加载需要状态为“已连接”。

## 2. 推荐操作顺序

建议按以下顺序完成一张一次图：

1. 在“场站”页签中创建场站。
2. 为场站维护 MCU，并为要使用的一次图绑定 MCU。
3. 新增一次图，拖入并编辑图元、连线。
4. 需要实时测点时，在“模版”页签导入设备类型和测点，再为设备绑定具体设备。
5. 点击“保存”，再使用“预览”检查画面与数据。
6. 确认无误后点击“发布”。

切换到另一张一次图，或准备新建一次图时，若当前画布有未保存的修改，工具会询问是否保存；选择“不保存”会继续切换，关闭该提示则留在当前画布。

## 3. 场站与一次图

### 3.1 新增和管理场站

1. 打开左侧“场站”页签，点击底部“管理场站”。
2. 点击“新增场站”。
3. 填写场站名称、详细地址和可选备注，点击“保存”。

场站名称不能与已有场站重复。管理窗口中可对场站执行“编辑”“删除”“MCU列表”和“一次图列表”。删除场站会同时删除其下的全部一次图。

### 3.2 配置 MCU

1. 在“管理场站”中，点击目标场站的“MCU列表”。
2. 点击“新增MCU”，填写 SN 号、IP 地址、通信端口和备注。
3. 完成每一行编辑后点击“完成”，最后点击“保存”。

SN 号和合法 IPv4 地址均为保存 MCU 的必填信息。同一场站内的 MCU 不允许 SN 或 IP 重复。一个场站可维护多个 MCU；一张一次图只能选择其中一台作为绑定 MCU。

### 3.3 新增、打开和编辑一次图

有两个新增入口：

- 在左侧展开场站，点击缩略图区域的“添加”。
- 在“管理场站 > 一次图列表”中点击“新增一次图”。

填写一次图名称和可选备注后，工具会清空画布并进入新图。一次图名称在同一场站内不能重复。新建记录会立即加入场站；完成绘制后点击顶部“保存”以写入最新画布内容。

打开已有图时，点击左侧的缩略图或图名；也可以在“一次图列表”中点击“打开组态”。左侧缩略图的右键菜单提供：

- **编辑**：修改一次图名称和备注。
- **绑定MCU**：为该图选择所属场站中的一台 MCU。
- **删除**：删除该一次图。

### 3.4 一次图列表

在“管理场站”中点击“一次图列表”，可查看该场站的图纸名称、已绑定设备数、未绑定设备数、绑定 MCU、发布状态和最后更新时间。

列表中的操作包括：

- **打开组态**：在编辑画布中打开此图。
- **绑定MCU**：从当前场站的 MCU 列表中单选一台并确认绑定。
- **预览**：打开预览窗口。
- **发布**：发布该图。
- **导出**：下载该图的 JSON 文件。
- **删除**：删除该图。

缩略图右上角出现“MCU”标识，表示该图已绑定 MCU；场站标题中的“已绑 n/m”表示已绑定 MCU 的图纸数量。

### 3.5 导入和导出

在“管理场站”窗口中：

- **导出场站工程包**：下载所有场站及其一次图的 JSON 工程包。
- **导入场站工程包**：选择 JSON 工程包导入场站数据。

在“一次图列表”中：

- 点击“导出”下载单张一次图 JSON。
- 点击“导入一次图”，拖入或选择本工具导出的 JSON 文件。

导入时会检查数据格式和名称重复。相同 ID 的场站或一次图会更新已有记录；不同 ID 但名称与当前场站内已有一次图重复时，不能导入。覆盖或删除重要内容前，建议先导出备份。

## 4. 图元库和设备模板

### 4.1 使用图元库

切换到左侧“图元”页签后：

1. 输入关键字搜索图元。搜索支持名称、别名、全拼和拼音首字母。
2. 展开所需分类。
3. 将图元拖到画布中的目标位置。

内置分类包括“系统组件”“一次设备”“电网”“新能源”“储能”“负荷”和“通信辅助”。悬停图元可查看名称和放大预览。

点击底部“管理”可打开“图库管理”：

- 勾选或取消勾选分类，控制其是否在图元栏显示。
- 在某个分类中查看图元。
- 点击“上传图元”导入自定义 SVG 图元；可选择现有分类或输入新分类名称后按 Enter 创建。
- 可删除自定义图元，或删除只包含自定义图元的自定义分类。

上传时仅支持 SVG 文件；图元名称和分类均不能为空，单个文件及其图元内容不能超过 256 KiB。

### 4.2 导入设备类型和测点

在左侧“模版”页签中：

1. 点击“导入Excel”，选择设备类型与测点文件（支持 `.xls`、`.xlsx`）。
2. 导入后，列表显示设备类型、类型和“已选测点数/总测点数”。
3. 点击设备类型所在行的“编辑”。
4. 勾选需要展示的测点，或使用“全选”“取消全选”。
5. 点击“保存配置”。

测点配置窗口可查看点名称、展示名称、属性标识、类型和单位。已选测点会用于后续设备绑定，并自动生成设备右侧的测点显示面板。

## 5. 绘制与编辑

### 5.1 添加、选择和移动

工具要求至少存在一个场站后才能在画布中添加图元、粘贴图元或绘制连线。

- 单击图元：单选。
- `Ctrl + 单击图元`：追加选择或取消选择该图元。
- 在空白画布拖出选择框：框选图元。
- 拖动已选图元：移动图元。
- 按住 `Space` 并左键拖动：平移画布。
- 在空白画布右键拖动：平移画布。
- 全局锁定后，左键拖动画布可直接平移，图元不能被编辑。
- `Ctrl + 鼠标滚轮`：以指针位置为中心缩放画布，范围为 10% 至 500%。

### 5.2 调整图元和属性

选中单个图元后，可拖动画布上的控制柄调整大小和旋转。按住 `Shift` 拖动缩放柄可临时保持宽高比例。

右侧“配置 > 边界和属性”可精确设置：

- X/Y 坐标。
- 宽度、高度和旋转角度。
- 隐藏、锁定、可缩放、等比缩放和可旋转。
- 图元本身提供的文字、颜色、数值、开关等专有属性。

系统连线不提供宽高、缩放和旋转设置。锁定图元后不能直接拖动或缩放，需先在配置中解除锁定。

### 5.3 页面设置

没有单选图元时，右侧显示“页面”设置，可：

- 查看当前画布尺寸，选择或输入画布缩放比例。
- 设置背景颜色。
- 上传或清除背景图片。仅支持图片，大小不超过 1 MiB。
- 设置“键盘移动距离”，默认值为 0.5。
- 开启或关闭参考线、吸附、网格、网格对齐，并设置网格大小。

开启网格对齐后，新增和拖动图元会按网格大小定位；参考线和吸附用于辅助图元对齐。

### 5.4 对齐、组合和图层顺序

选择两个或更多非连线图元后，顶部“对齐”菜单可执行：左对齐、右对齐、水平居中和垂直居中。

- 点击“组合”可将多个已选图元作为整体操作。
- 单选一个组合后点击“取消组合”可还原其成员。
- 在图元上右键可使用复制、删除、组合/取消组合及图层顺序命令。

图层顺序命令包括置顶、上移一层、下移一层和置底。它们只适用于单选图元。

### 5.5 连线

1. 点击顶部“连线”使其高亮，进入连线模式。
2. 在弹出菜单中选择“自由”“竖线”或“横线”。
3. 在画布上按住并拖动，生成连线。
4. 再次点击“连线”退出连线模式。

“竖线”和“横线”会固定连线方向；自由模式则跟随拖动方向。拖动连线端点或节点时，按住 `Ctrl` 可锁定水平方向变化，按住 `Shift` 可锁定垂直方向变化。连线靠近图元边缘中点时可附着到该图元，移动、缩放或旋转图元后，已附着的连线会跟随更新。

### 5.6 组件树和画布复位

- 点击顶部“组件树”打开“图形结构树”。在树中点击节点可选中对应图元；眼睛图标可切换显示或隐藏状态。
- 点击顶部“复位”只恢复当前画布的缩放和平移视图，不会删除或改动图元内容。

## 6. 设备绑定

设备绑定需要先导入设备类型与测点模板，并进入一个已绑定 MCU 的一次图。加载设备列表前，底部连接状态必须为“已连接”。

1. 在画布中选中要关联的设备图元。
2. 在右侧切换到“绑定”。
3. 选择“设备类型”。系统会按该类型的已选测点生成或刷新设备右侧的测点面板。
4. 点击“加载设备列表”。
5. 在“选择设备”窗口中单选设备，点击“确定”。
6. 如需调整展示测点，点击“配置测点”，修改勾选项并保存。

自动生成的测点面板会逐项展示所选测点的名称、数值和单位，并随模板配置更新。已绑定的设备名称会显示在“设备列表”区域。

对于文本、系统按钮和键值对图元，绑定面板还会按图元能力提供“键名写到”或“值写到”选项，用于指定设备字段应写入图元的哪个显示属性。自动生成的测点面板本身不提供再次绑定入口。

若无法加载设备列表，请先检查：当前图纸是否已绑定 MCU、MCU 是否填写有效 IPv4 地址，以及底部状态是否为“已连接”。

## 7. 保存、缩略图、预览和发布

### 7.1 保存与缩略图下载

点击顶部“保存”会保存当前一次图，更新最近更新时间、缩略图和设备绑定统计。

顶部“缩略图”用于下载当前画布文件：

- 默认点击下载 PNG 图像。
- 在下拉菜单中选择“SVG”下载矢量 SVG 文件。

“缩略图”下载不会替代“保存”；需要将当前画布写入一次图时，仍应点击“保存”。

### 7.2 预览

点击顶部“预览”，或在一次图列表中点击“预览”，会在当前页面打开预览窗口。

- 左键拖动：平移预览画布。
- `Ctrl + 鼠标滚轮`：缩放预览，范围为 10% 至 500%。

图中已有设备测点绑定时，预览会尝试读取实时数据。若当前场站没有可用 MCU、连接不可用或数据读取失败，仍可继续以静态图纸预览。

### 7.3 发布

点击顶部“发布”后，在确认窗口中选择“确定发布”；也可以在一次图列表中直接对指定图纸点击“发布”。

发布前请确认：

1. 当前一次图属于一个已创建场站。
2. 该图已绑定 MCU，且 MCU 配置了有效 IP 地址。
3. 图纸内容已检查完毕；建议先保存并预览。

发布成功后，该图在所属场站中显示“已发布”，同一场站的其他图纸会显示“未发布”。

## 8. 快捷键

画布快捷键在编辑画布获得焦点时生效。点击输入框、侧栏或弹窗后，请先点击画布再使用。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + A` | 全选画布图元 |
| `Ctrl + C` | 复制所选图元 |
| `Ctrl + V` | 粘贴图元，并相对原位置偏移 |
| `Delete` | 删除所选图元 |
| `Ctrl + G` | 组合所选图元 |
| `Ctrl + U` | 取消所选组合 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `Ctrl + →` | 将单选图元置顶 |
| `Ctrl + ↑` | 将单选图元上移一层 |
| `Ctrl + ↓` | 将单选图元下移一层 |
| `Ctrl + ←` | 将单选图元置底 |
| `↑` `↓` `←` `→` | 按“键盘移动距离”移动所选图元 |
| `Shift + ↑/↓/←/→` | 以键盘移动距离的 10 倍快速移动所选图元 |
| `Space` + 左键拖动 | 平移编辑画布 |
| `Ctrl` + 鼠标滚轮 | 缩放编辑或预览画布 |
| `Ctrl` + 单击图元 | 追加选择或取消选择 |
| `Shift` + 拖动缩放柄 | 临时等比缩放 |

快捷键按实际实现使用 `Ctrl`。在 macOS 上同样使用 `Control`，不使用 `Command`。

## 9. 常见提示

- **“请先添加场站”**：先在“场站 > 管理场站”创建至少一个场站。
- **“该场站暂无一次图”**：在该场站左侧卡片点击“添加”，或在“一次图列表”中点击“新增一次图”。
- **设备列表按钮不可用或提示未连接**：为当前图纸绑定 MCU，检查其 IPv4 地址，并等待底部状态变为“已连接”。
- **无法发布**：确认当前图已绑定 MCU 且 MCU 配置 IP；建议先保存图纸。
- **预览没有实时数值**：检查设备绑定、测点配置和 MCU 连接。实时数据不可用时仍可查看静态图纸。
- **快捷键没有反应**：先点击画布，使编辑区重新获得焦点。
