# 一次接线图组态工具用户指南

本指南适用于“砺行能源一次接线图组态工具 v2.0”，介绍场站、一次接线图、图元、设备绑定、预览与发布等最终用户操作。

## 1. 界面概览

打开工具后进入一次接线图编辑页，界面分为以下区域：

- **顶部工具栏**：撤销、重做、复位画布、删除、组件树、对齐、组合、连线、保存、生成缩略图、预览、发布、在线校验、全屏、全局锁定和日间/夜间模式。
- **左侧栏**：包含“场站”“图元”“模版”三个页签。
- **中间画布**：放置、选择、移动、缩放、旋转和连接图元。
- **右侧栏**：未单选图元时显示页面设置；单选图元时显示图元“配置”和“绑定”。
- **底部状态栏**：显示最近更新时间、当前场站、当前图纸，以及当前一次图所绑定 MCU 的连接状态。

顶部左右两侧的折叠按钮可分别收起或展开侧栏。右上角还可切换全屏、锁定整个画布及日间/夜间模式。

## 2. 场站管理

绘制一次接线图前必须先添加场站，否则在画布添加图元或连线时会提示“请先添加场站”。

### 2.1 添加场站

1. 在左侧选择“场站”。
2. 点击底部的“管理场站”。
3. 点击“添加场站”。
4. 填写场站名称、详细地址和备注，其中场站名称、详细地址为必填项。
5. 点击“保存”。

在“管理场站”窗口中，可对已有场站执行编辑、删除、查看 MCU 列表和进入场站操作。删除场站会同时移除其中保存的一次接线图，请按确认提示操作。

### 2.2 配置场站 MCU

1. 打开“管理场站”。
2. 在目标场站行点击“MCU列表”。
3. 点击“新增MCU”，填写 SN 号、IP 地址、通信端口和备注。SN 号为必填项。
4. 可点击“完成”结束当前行编辑，也可继续新增或编辑其他 MCU。
5. 点击窗口底部“保存”。

一个场站可以保存多个 MCU。获取设备、实时预览和发布依赖 MCU 的连接信息，其中 IP 地址必须正确配置。

## 3. 一次接线图管理

### 3.1 新建一次接线图

可以通过以下任一入口新建：

- 展开左侧某个场站，点击缩略图列表中的“添加”。
- 在“管理场站”中点击“进入场站”，再点击“新增一次图”。

输入一次接线图名称和可选备注并保存后，画布会被清空并进入新图绘制状态。完成绘制后必须点击顶部“保存”，一次图才会写入场站并生成缩略图。

### 3.2 打开已有一次图

- 在左侧展开场站，点击一次图缩略图；或
- 进入“场站详情”，在一次图列表中点击“打开组态”。

打开后，底部会显示当前场站、图纸名称、最近更新时间及 MCU 连接状态。

### 3.3 场站详情中的一次图操作

在“管理场站”中点击“进入场站”，可查看一次图名称、绑定设备总数、未绑定设备数、绑定 MCU、发布状态和最后更新时间，并执行：

- **打开组态**：进入编辑画布。
- **绑定MCU**：为该一次图选择当前场站下的一台 MCU。
- **预览**：直接预览该图。
- **发布**：将该图发布到场站 MCU。
- **导出**：导出该一次图 JSON 包。
- **删除**：删除该一次图。

“进入场站”按钮本身会加载该场站的第一张一次图；若场站内没有一次图，会显示相应提示。

### 3.4 为一次图绑定 MCU

1. 先在场站的“MCU列表”中添加并保存 MCU。
2. 进入场站详情，在目标一次图行点击“绑定MCU”。
3. 在列表中单选一台 MCU。
4. 点击“确定绑定”。

绑定后，一次图列表会显示 MCU 的 SN 或 IP，底部连接状态也将按该一次图绑定的 MCU IP 进行检测。

## 4. 绘制和编辑图形

### 4.1 添加图元

1. 在左侧选择“图元”。
2. 可输入关键字搜索，也可展开分类查找图元。
3. 将图元拖到中间画布。

鼠标悬停图元缩略图时会显示名称和放大预览。点击左侧底部“管理”可选择需要展示的图库分类。

### 4.2 选择和移动

- 单击图元：单选。
- 按住 `Ctrl` 单击图元：追加选择或取消该图元的选择。
- 在画布空白处拖出选择框：框选多个图元。
- 拖动已选图元：移动位置。
- 方向键：将所选图元每次移动 1 像素。

按住空格并用鼠标左键拖动可平移画布。画布全局锁定后，也可以用鼠标左键拖动画布；鼠标右键拖动同样可平移画布。

### 4.3 缩放和复位画布

- 在画布上按住 `Ctrl` 滚动鼠标滚轮：以鼠标位置为中心缩放，范围为 10% 至 500%。
- 点击顶部“复位画布位置/大小”：恢复当前一次图初始的画布视图。

### 4.4 调整图元

选中图元后，可以通过画布上的控制柄缩放或旋转。按住 `Shift` 拖动缩放控制柄可临时保持宽高比例。

右侧“配置 > 边界和属性”还可精确修改：

- 标题、X/Y 坐标、宽度、高度和旋转角度。
- 隐藏、锁定、可缩放、等比缩放和可旋转。
- 图元自身提供的文字、颜色、图片、数值等专有属性。

系统连线不提供普通图元的宽高、缩放和旋转设置。

### 4.5 对齐、分布和组合

选择至少两个图元后，可使用顶部“对齐”菜单执行左对齐、水平居中、右对齐、上对齐、垂直居中、下对齐、水平分布和垂直分布。

- 选择多个图元后点击“组合”，可把它们作为整体操作。
- 单选一个组合后点击“取消组合”，可还原其中的图元。

### 4.6 图层顺序和右键菜单

在画布中右键可使用当前状态允许的操作，包括全选、复制、粘贴、删除、组合、取消组合、置顶、上移、下移和置底。也可使用对应快捷键调整图层顺序。

### 4.7 绘制连线

1. 点击顶部“连线编辑模式”图标使其进入选中状态。
2. 在画布中开始绘制系统连线，并按需要连接图元锚点。
3. 再次点击该图标退出连线编辑模式。

拖动连线节点时，按住 `Ctrl` 可锁定水平方向变化，按住 `Shift` 可锁定垂直方向变化。

### 4.8 组件树

点击顶部“组件树”打开“图形结构树”抽屉。可在树中定位并选择图元，也可切换图元的显示/隐藏状态。组合图元会以层级结构展示。

## 5. 页面设置

当没有单选某个图元时，右侧显示“页面”设置，可配置：

- 画布尺寸和缩放倍数。
- 背景颜色和背景图片。
- 参考线与吸附。
- 网格、网格对齐和网格大小。

开启网格对齐后，新增或移动内容会按网格设置对齐；参考线和吸附用于辅助图元之间的定位。

## 6. 设备类型和测点模板

左侧“模版”页签用于维护设备类型及其测点：

1. 点击“导入Excel”，选择设备类型与测点 Excel 文件。桌面版在可用时还会显示“从默认路径导入”。
2. 导入后，列表显示设备类型、类型编码以及“已选测点数/总测点数”。
3. 点击某设备类型的“编辑”。
4. 勾选需要展示的测点，或使用“全选”“取消全选”。
5. 点击“保存配置”。

这里选择的测点会作为后续图元设备绑定时的预设属性。

## 7. 设备绑定

### 7.1 将图元绑定到设备

1. 在画布中单选图元。
2. 在右侧切换到“绑定”。
3. 选择“设备类型”。
4. 点击“加载设备列表”，再从列表中选择具体设备。
5. 检查该模板预设的“属性”测点。
6. 若图元支持，选择“键名写到”和“值写到”的目标属性。

文本、按钮或键值对等能展示数值的图元可以绑定实时值；卡片通常作为容器，本身不用于展示数值。键名会写入所选名称属性，键值会从实时接口读取相应测点数据。

### 7.2 在线校验

点击顶部“在线校验”可查看当前一次图中所有未绑定设备。列表中的“定位”会关闭窗口并在画布中选中对应图元，便于继续完成绑定。

场站详情中的“绑定设备总数”和“未绑定设备数”在保存一次图时更新。

## 8. 保存、缩略图、预览和发布

### 8.1 保存

点击顶部“保存”保存当前一次图。保存时会同时：

- 更新一次图内容和最近更新时间。
- 生成并保存缩略图。
- 统计已绑定和未绑定设备数量。

新建一次图后必须至少保存一次，才能在场站中形成正式记录并用于发布。

顶部“生成缩略图”可单独重新生成当前画布缩略图。

### 8.2 预览

点击顶部“预览”，或在场站详情中点击某张图的“预览”。预览会在新页面显示完整画布：

- 鼠标左键拖动：平移预览画布。
- `Ctrl + 鼠标滚轮`：缩放预览画布，范围为 10% 至 500%。

若图中存在设备绑定，系统会尝试通过场站 MCU 获取实时数据；未确定场站、未配置 MCU/IP 或接口异常时，会给出提示，图纸仍可按静态数据预览。

### 8.3 发布

发布前应确保：

1. 当前一次图已经保存。
2. 当前场站已配置带 IP 地址的 MCU。
3. 一次图内容和设备绑定已经完成，并建议先执行在线校验。

可点击顶部“发布”，也可在场站详情中对指定一次图点击“发布”。发布成功后，该图状态变为“已发布”；同一场站中其他一次图会显示为“未发布”。

## 9. 导入和导出

### 9.1 场站工程包

在“管理场站”中：

- 点击“导出场站工程包”，将全部场站及其一次图导出为 JSON 文件。
- 点击“导入场站工程包”，选择符合格式的 JSON 文件。有效场站会保存到本地；相同 ID 的场站会更新现有记录。

### 9.2 单张一次图

进入场站详情：

- 点击一次图行的“导出”，导出该图及其元数据。
- 点击顶部“导入一次图”，拖入或选择本工具导出的 JSON 文件。

导入的一次图 ID 若已存在于当前场站，会覆盖原记录；否则作为新图追加。重要内容在覆盖前建议先导出备份。

## 10. 快捷键

快捷键在编辑画布获得操作焦点时生效。点击输入框、侧栏或弹窗后，请先重新点击画布再使用画布快捷键。

| 快捷键                  | 功能                            |
| ----------------------- | ------------------------------- |
| `Ctrl + A`              | 全选画布图元                    |
| `Ctrl + C`              | 复制所选图元                    |
| `Ctrl + V`              | 粘贴图元，并相对原位置偏移      |
| `Delete`                | 删除所选图元                    |
| `Ctrl + G`              | 组合所选图元                    |
| `Ctrl + U`              | 取消所选组合                    |
| `Ctrl + Z`              | 撤销                            |
| `Ctrl + Y`              | 重做                            |
| `Ctrl + →`              | 将所选图元置顶                  |
| `Ctrl + ↑`              | 将所选图元上移一层              |
| `Ctrl + ↓`              | 将所选图元下移一层              |
| `Ctrl + ←`              | 将所选图元置底                  |
| `↑` `↓` `←` `→`         | 将所选图元向对应方向移动 1 像素 |
| 按住 `Space` 并左键拖动 | 平移编辑画布                    |
| `Ctrl + 鼠标滚轮`       | 缩放编辑或预览画布              |
| `Ctrl + 单击图元`       | 追加选择或取消选择              |
| `Shift + 拖动缩放柄`    | 临时等比缩放图元                |

> 快捷键按代码中的实际实现使用 `Ctrl`。在 macOS 上也应使用 `Control`，工具未将 `Command` 映射为这些编辑快捷键。

## 11. 常见提示

- **请先添加场站**：当前没有场站，先在“场站 > 管理场站”中添加。
- **该场站暂无一次图**：先在左侧场站卡片或场站详情中新增一次图。
- **请先进入场站后再获取设备列表**：先打开当前场站的一次图，再执行设备绑定。
- **场站尚未绑定 MCU 或未配置 IP**：在“管理场站 > MCU列表”中补充并保存 MCU 连接信息。
- **无法发布**：确认一次图已保存、场站 MCU 已配置 IP，并且当前编辑上下文属于该场站。
- **预览没有实时数据**：检查图元绑定、场站 MCU/IP 和设备接口连接；静态图纸仍可预览。
- **快捷键无响应**：先点击画布，使编辑画布重新获得操作焦点。
