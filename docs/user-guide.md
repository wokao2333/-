# 一次接线图组态工具用户指南

本指南以当前编辑页中实际显示的页面、菜单、按钮和提示为准，介绍创建场站、绘制一次接线图、绑定设备、预览和发布的操作。编辑页对应路由为 `/` 和 `/edit`。

## 1. 开始使用

### 1.1 使用前准备

- 至少创建一个场站后，才能向画布拖入图元、粘贴图元或绘制连线。
- 需要加载真实设备、读取实时测点或发布一次图时，需要为一次图绑定 MCU，并填写有效的 IP 地址。
- 需要进行设备绑定时，先在“模版”页签导入设备类型和测点文件。

### 1.2 工作区

编辑页包括以下区域：

- **顶部工具栏**：`撤销`、`重做`、`复位`、`删除`、`组件树`、`对齐`、`组合`、`取消组合`、`连线`、`保存`、`缩略图`、`预览`和`发布`。
- **左侧栏**：`场站`、`图元`、`模版`三个页签。
- **中央画布**：放置、选择和编辑一次接线图。
- **右侧栏**：未单选图元时显示`页面`设置；单选一个图元时显示`配置`，支持设备绑定的图元还会显示`绑定`。
- **底部状态栏**：显示`最近更新`、`场站`、`图纸`以及连接状态（`连接检测中…`、`已连接 · v版本号`或`未连接`）；连接状态由当前一次图所绑定 MCU 的健康检查接口 `GET /business/monitor/health` 探测得出，悬停可查看接口地址、服务版本、服务时间或失败原因。

顶部左右两侧的菜单按钮可以分别折叠或展开侧栏。右上角还可以使用`全屏`、`锁定`和日间/夜间模式按钮。锁定按钮的提示为`已解锁 (点击锁定)`或`已锁定 (点击解锁)`。

### 1.3 推荐操作顺序

1. 在`场站`页签中点击`管理场站`，创建场站。
2. 在`MCU列表`中维护 MCU 信息。
3. 创建一次图，为一次图绑定 MCU。
4. 在`图元`页签拖入图元并完成绘制。
5. 如需设备数据，在`模版`页签导入设备类型和测点，并在图元的`绑定`页签中绑定真实设备。
6. 点击`保存`，再点击`预览`检查画面。
7. 确认无误后点击`发布`。

切换一次图或新建一次图时，如果当前画布有未保存的修改，会显示“当前画布有未保存的修改，是否保存后再继续？”：

- 点击`保存`：保存当前画布后继续。
- 点击`不保存`：放弃当前未保存修改并继续。
- 关闭提示窗口或按 `Esc`：留在当前画布。

## 2. 管理场站和一次图

### 2.1 创建和编辑场站

1. 打开左侧`场站`页签。
2. 点击`管理场站`。
3. 点击`新增场站`。
4. 填写`场站名称`和`详细地址`，也可以填写`备注`。
5. 点击`保存`。

`场站名称`和`详细地址`为必填项。名称会自动去除首尾空格，场站名称不能与已有场站重复。保存成功后会提示`场站添加成功`。

在`管理场站`列表中可以使用：

- `编辑`：修改`场站名称`、`详细地址`和`备注`。
- `删除`：删除场站及其下的全部一次图。确认提示为“确定删除该场站吗？场站下所有一次图也将被删除。”
- `MCU列表`：维护该场站的 MCU。
- `一次图列表`：打开该场站的详情和一次图列表。
- `导入场站工程包`、`导出场站工程包`：导入或导出场站数据。

### 2.2 维护 MCU

1. 在`管理场站`中点击目标场站的`MCU列表`。
2. 在“绑定MCU”窗口中点击`新增MCU`。
3. 填写`SN号`、`IP地址`、`通信端口`和`备注`。
4. 单行编辑完成后点击该行的`完成`；需要修改已有记录时点击该行的`编辑`。
5. 点击窗口底部的`保存`。

`SN号`和`IP地址`为必填项。IP 地址必须是有效的 IPv4 地址，例如 `192.168.1.1`；端口和备注可以不填。同一场站内的 MCU 不能使用相同的 SN 号或 IP 地址。保存成功后提示`MCU绑定信息已保存`。

如果 IP 地址不合法，页面会提示具体原因，例如：

- `IP 地址不能为空，请输入有效的 IPv4 地址`
- `IP 地址必须由 4 段数字组成，并以点号分隔（如 192.168.1.1）`
- `IP 地址每段的数值必须在 0-255 之间`

### 2.3 创建一次图

有两种创建入口：

- 在左侧展开目标场站，点击一次图列表中的`添加`。
- 点击`管理场站`，在目标场站行点击`一次图列表`，再点击`新增一次图`。

在“新增一次接线图”窗口中：

1. 填写`名称`。
2. 按需填写`备注（选填）`。
3. 点击`保存`。

一次图名称不能为空或只能包含空格，且同一场站内不能重复。创建成功后会提示`一次接线图“<名称>”已添加并选中`，画布会清空并进入新图。

### 2.4 打开、编辑和删除一次图

- 在左侧场站卡片中点击一次图缩略图或图名，可以打开一次图。
- 在`场站详情 - <场站名称>`窗口中点击`打开组态`，可以打开一次图。
- 右键点击左侧一次图缩略图，可以使用`编辑`、`绑定MCU`和`删除`。
- 编辑一次图时可以修改名称和备注，窗口标题为“编辑一次接线图”。
- 删除一次图前会显示“确定删除该一次接线图吗？”的确认提示。

打开成功后会提示`一次图加载成功`。如果当前场站没有一次图，进入场站时会提示`该场站暂无一次图`。

### 2.5 一次图列表

在`场站详情 - <场站名称>`窗口中，`一次接线图列表`显示：

- `一次图名称`
- `绑定设备总数`
- `未绑定设备数`
- `绑定MCU`
- `状态`：`已发布`或`未发布`
- `最后更新时间`

列表操作包括：

- `打开组态`
- `绑定MCU`
- `预览`
- `发布`
- `导出`
- `删除`

一次图已绑定 MCU 时，左侧缩略图右上角会显示`MCU`标记；场站标题中的`已绑 n/m`表示该场站中已绑定 MCU 的一次图数量。

### 2.6 为一次图绑定 MCU

1. 在`一次图列表`中点击目标图的`绑定MCU`，或右键缩略图后点击`绑定MCU`。
2. 在“为一次图“<名称>”绑定MCU”窗口中单选一行 MCU。
3. 点击`确定绑定`。

窗口显示`SN`、`IP`、`端口`、`备注`和`当前绑定`。同一张一次图只能选择一台 MCU。没有 MCU 时会提示“该场站暂无可绑定的 MCU，请先在场站管理中添加 MCU”；未选择时点击确认会提示`请选择要绑定的 MCU`。

### 2.7 导入和导出

在`管理场站`窗口中：

- 点击`导出场站工程包`，下载包含场站及其一次图的 JSON 工程包。
- 点击`导入场站工程包`，选择 JSON 文件导入场站数据。导入成功会提示`已导入 n 个场站工程包`；重复数据会被跳过并在提示中列出。

在`一次接线图列表`中：

1. 点击`导入一次图`。
2. 将 JSON 文件拖到上传区域，或点击`点击上传`选择文件。
3. 文件必须是本工具导出的“一次图” JSON 文件。

导入一次图成功后，会提示`已导入一次图“<名称>”并保存至本地数据库`。同 ID 的一次图会覆盖更新；同一场站内名称重复的一次图不能导入。导出一次图使用列表中的`导出`按钮。

## 3. 图元和测点模板

### 3.1 使用图元

1. 打开左侧`图元`页签。
2. 在搜索框`请输入关键字进行搜索`中输入名称、别名、全拼或拼音首字母。
3. 展开分类，找到需要的图元。
4. 将图元拖到画布中的目标位置。

当前内置分类包括：

- `系统组件`
- `一次设备`
- `电网`
- `新能源`
- `储能`
- `负荷`
- `通信辅助`

将鼠标悬停在图元上可以查看名称和放大预览。部分设备类图元拖入画布后会同时生成设备名称标签；生成的对象可以继续选择和编辑。

### 3.2 管理图元库

1. 在`图元`页签底部点击`管理`。
2. 在“图库管理”窗口中使用分类树和`全选`控制分类是否显示在图元栏。
3. 选中分类后，可以查看该分类中的图元。

上传自定义图元：

1. 点击`上传图元`。
2. 在“上传 SVG 图元”窗口填写`图元名称`。
3. 在`所属分类`中选择已有分类，或输入新分类名称后按 `Enter` 创建。
4. 点击`选择 SVG`，选择 SVG 文件。
5. 点击`上传`。

上传只支持 SVG 文件，文件和图元内容均不能超过 256 KiB。`图元名称`和`所属分类`不能为空且不能超过 64 个字符；`系统组件`是系统保留分类，不能作为自定义分类。上传成功后会提示`图元“<名称>”上传成功`。

自定义图元右上角的`删除`按钮可以删除图元；删除前会提示删除后，使用该图元的已保存图纸可能无法还原。只包含上传图元的自定义分类可以使用`删除分类`删除。

### 3.3 导入设备类型和测点

1. 打开左侧`模版`页签。
2. 点击`导入Excel`，选择 `.xls` 或 `.xlsx` 文件。
3. 导入完成后，列表显示`设备类型`、`类型`、`测点`和`操作`。
4. 在目标设备类型行点击`编辑`。
5. 在“配置测点 - <设备类型>”窗口中勾选要展示的测点，或点击`全选`、`取消全选`。
6. 点击`保存配置`。

设备类型与测点 Excel 使用以下列名：`类型`、`类型名称`、`属性标识`、`点名称`、`展示名称`、`数值类型`、`单位`、`是否默认选中`和`排序`。导入成功后提示`已导入 n 条测点`；文件无法解析时提示`Excel 解析或导入失败`。

测点配置窗口会显示`点名称`、`展示名称`、`属性标识`、`类型`和`单位`。保存成功后提示`测点配置已保存`，所选测点会用于后续设备绑定和测点显示。

## 4. 绘制和编辑

### 4.1 选择、移动和缩放画布

在画布中：

- 单击图元：单选。
- 按住 `Ctrl` 单击图元：追加选择或取消选择。
- 在空白区域拖动：框选图元。
- 拖动已选图元：移动图元。
- 按住 `Space` 并按住鼠标左键拖动：平移画布。
- 在空白画布上按住鼠标右键拖动：平移画布。
- 按住 `Ctrl` 滚动鼠标滚轮：以鼠标位置为中心缩放，范围为 10% 至 500%。

画布没有场站时，添加图元、粘贴图元或绘制连线会提示`请先添加场站`。全局锁定后，图元不能编辑；在画布上拖动可以平移画布。尝试在锁定画布中添加图元时会提示`画布已锁定，请先解锁！`。

### 4.2 编辑图元属性

1. 单选一个图元。
2. 在右侧打开`配置`页签。
3. 展开`边界和属性`。
4. 修改需要的字段。

可见字段包括：

- `标题`
- `x轴坐标`、`y轴坐标`
- `宽度`、`高度`
- `旋转角度`
- `隐藏`、`锁定`
- `可缩放`、`等比缩放`、`可旋转`

连线不显示`宽度`、`高度`、`旋转角度`和缩放/旋转开关。不同图元还会显示自己的属性，例如文字、颜色、线条宽度、箭头、动画或键值内容。图元锁定后不能直接拖动或缩放；先在`配置`中关闭`锁定`。

### 4.3 页面设置

未选中图元时，右侧显示`页面`页签，可设置：

- `画布尺寸`：只读显示当前尺寸。
- `缩放倍数`：可选择 `0.5`、`1`、`1.5`、`2`，也可以使用`自定义`输入值。
- `背景颜色`。
- `键盘移动距离`：默认值为 `0.5`，最小值为 `0.1`。
- `背景图片`：点击上传按钮选择图片；悬停已有图片时点击删除图标可清除。
- `参考线`。
- `吸附`。
- `网格`。
- `网格对齐`和`网格大小`：开启`网格`后显示。

背景图片只支持图片文件，大小不能超过 1MB。错误提示为`只能上传图片!`或`不能上传超过1MB的图像!`。开启`网格对齐`后，新增和移动图元会按`网格大小`定位。

### 4.4 对齐、组合和图层顺序

选择两个或更多非连线图元后，点击顶部`对齐`，再选择：

- `左对齐`
- `右对齐`
- `水平居中`
- `垂直居中`

选择多个图元后：

- 点击`组合`，将它们作为一个整体操作。
- 单选组合后点击`取消组合`，恢复组合成员。

右键点击图元可以使用`复制`、`删除`、`组合`、`取消组合`、`置顶`、`上移`、`下移`和`置底`。图层顺序操作只对单选图元生效；已经位于最上层或最下层时，会分别提示`已经是最上层了`或`已经是最下层了`。

在空白画布上右键时，根据当前内容可能显示`全选`或`粘贴`。

### 4.5 绘制连线

1. 点击顶部`连线`。
2. 在弹出的`连线模式`中选择`自由`、`竖线`或`横线`。
3. 在画布上按住鼠标左键拖动，绘制连线。
4. 再次点击`连线`退出连线模式。

`自由`模式不限制方向，`竖线`模式保持垂直，`横线`模式保持水平。拖动连线端点或节点时：

- 按住 `Ctrl`：保持 x 坐标不变，只沿垂直方向移动。
- 按住 `Shift`：保持 y 坐标不变，只沿水平方向移动。

连线端点靠近图元边缘中点时可以附着到图元。图元移动、缩放或旋转后，已附着的连线会跟随更新。

### 4.6 组件树和复位

- 点击`组件树`，打开`图形结构树`。点击节点可选中图元，节点右侧的眼睛图标可切换`显示`或`隐藏`。
- 点击`复位`，恢复当前一次图的画布缩放和平移视图，不会删除或修改图元内容。
- `撤销`和`重做`用于回退或恢复画布编辑操作；没有可用历史记录时按钮不可用。

## 5. 绑定设备和测点

### 5.1 绑定真实设备

先完成以下准备：

1. 在`模版`页签导入设备类型和测点。
2. 打开一个已绑定 MCU 的一次图。
3. 等待底部状态栏显示`已连接`。

然后按以下步骤绑定：

1. 在画布中单选可绑定的设备图元。
2. 在右侧打开`绑定`页签。
3. 在`设备类型`中选择设备类型。
4. 点击`加载设备列表`。
5. 在“选择设备”窗口中单选一行设备。
6. 点击`确定`。

“选择设备”窗口显示`序号`和`设备名称`，设备较多时可以翻页或将每页数量调整为 `10`、`20` 或 `50`。绑定成功后，右侧`设备列表`区域显示`已绑定：<设备名称>`。

### 5.2 配置测点和显示属性

- 右侧`属性`区域显示当前设备类型已选择的测点。
- 点击`配置测点`可以重新打开测点配置窗口，调整选择后点击`保存配置`。
- 如果当前图元支持写入设备名称或设备数值，页面还会显示`键名写到`和`值写到`，可分别选择写入的显示属性。
- 由测点配置生成的测点显示面板不能再次打开`绑定`页签。

### 5.3 绑定时的提示

- 未选择设备类型时，点击相关按钮会提示`请先选择设备类型`。
- 连接检测中时会提示`连接状态检测中，请稍后再试`；未连接时会提示`当前未连接MCU服务，请检查 MCU 地址后重试`。
- 没有进入场站时会提示`请先进入场站后再获取设备列表`。
- 场站没有绑定 MCU 或 MCU 没有 IP 地址时会提示`该场站尚未绑定MCU或未配置IP，无法获取设备列表`。
- 设备类型没有可用设备时，窗口显示`该设备类型下暂无设备`。
- 未选择设备时点击`确定`会提示`请选择设备`。

## 6. 保存、预览和发布

### 6.1 保存一次图

在已打开的一次图中点击顶部`保存`：

1. 工具保存当前画布内容。
2. 更新一次图的缩略图、绑定设备统计和`最后更新时间`。
3. 成功提示`一次图保存成功`。

如果无法生成缩略图，会提示`生成缩略图失败`；保存失败会提示`保存一次图失败，请重试`。`缩略图`下载不会替代`保存`。

### 6.2 下载缩略图

1. 点击顶部`缩略图`。
2. 在`缩略图格式`中选择：
   - `PNG`：下载 PNG 缩略图。
   - `SVG`：下载矢量 SVG 缩略图。

### 6.3 预览一次图

点击顶部`预览`，或在一次图列表中点击`预览`，会打开标题为`预览`的窗口。预览窗口支持：

- 按住鼠标左键拖动：平移预览画布。
- 按住 `Ctrl` 滚动鼠标滚轮：缩放预览画布。

如果图中存在设备测点绑定，工具会尝试读取实时数据：

- 成功时提示`实时数据已绑定到预览`。
- 场站或 MCU 信息不完整时，仍会打开静态图预览，并提示`当前场站尚未绑定MCU或未配置IP，无法获取实时数据`。
- 获取失败时提示`获取实时数据失败: <错误信息>`，仍可继续查看静态图。

### 6.4 发布一次图

顶部发布：

1. 点击顶部`发布`。
2. 在“发布确认”窗口点击`确定发布`；取消时点击`取消`。

发布前需要当前画布属于一个已保存的一次图，且该一次图已绑定 MCU 并配置有效 IP。发布成功后提示`发布成功`，一次图列表中的`状态`变为`已发布`，同一场站的其他一次图会显示`未发布`。

常见提示：

- `请先选择或保存一次接线图后再发布`
- `当前一次图尚未绑定MCU或MCU未配置IP，无法发布`
- `发布失败: <错误信息>`
- 如果远端发布成功但本地状态保存失败，会提示`发布成功，但本地发布状态保存失败: <错误信息>`

在一次图列表中点击`发布`可以直接发布指定一次图，不需要先打开该图。

## 7. 快捷键

快捷键在编辑画布获得焦点时生效。点击输入框、侧栏或弹窗后，请先点击画布。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + A` | 全选画布图元 |
| `Ctrl + C` | 复制所选图元，提示`复制成功` |
| `Ctrl + V` | 粘贴图元，并产生位置偏移 |
| `Delete` | 删除所选图元 |
| `Ctrl + G` | 组合所选图元 |
| `Ctrl + U` | 取消组合 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `Ctrl + Right` | 置顶 |
| `Ctrl + Up` | 上移一层 |
| `Ctrl + Down` | 下移一层 |
| `Ctrl + Left` | 置底 |
| `↑` `↓` `←` `→` | 按`键盘移动距离`移动所选图元 |
| `Shift + ↑/↓/←/→` | 按`键盘移动距离`的 10 倍移动所选图元 |
| `Space` + 鼠标左键拖动 | 平移编辑画布 |
| `Ctrl` + 鼠标滚轮 | 缩放编辑画布或预览画布 |
| `Ctrl` + 单击图元 | 追加选择或取消选择 |
| `Shift` + 拖动缩放柄 | 临时等比缩放 |

快捷键按当前实现使用 `Ctrl`。在 macOS 上也使用 `Control`，不使用 `Command`。

## 8. 常见问题

- **提示“请先添加场站”**：在`场站 > 管理场站 > 新增场站`创建至少一个场站。
- **场站中没有一次图**：在场站卡片中点击`添加`，或在`一次图列表`中点击`新增一次图`。
- **设备列表无法加载**：确认当前一次图已绑定 MCU、MCU 已填写有效 IP，并等待底部显示`已连接`。
- **提示“请先选择设备类型”**：先在右侧`绑定`页签中选择`设备类型`。
- **Excel 导入失败**：确认文件为 `.xls` 或 `.xlsx`，并包含可识别的设备类型和测点列。
- **预览没有实时数值**：检查设备绑定、测点选择、MCU IP 和底部连接状态；实时数据不可用时仍可查看静态图。
- **发布失败**：确认一次图已经保存、已绑定 MCU 且 MCU 的 IP 地址可用。
- **快捷键没有反应**：先点击中央画布，使编辑区重新获得焦点。
